# Workarounds

Other people's bugs this repo works around. A workaround with no record reads as
ordinary repo logic and outlives its cause by years, so each row keeps evidence
that the bug is somebody else's plus the check that says whether it is still
alive; when the check stops holding, drop the workaround and the row.

`sNN` = `home/.chezmoiscripts/*_NN-*.sh.tmpl`, catalog = `home/.chezmoidata.yaml`.
Evidence is one of four states, the last two as legitimate as the first two:
**U** upstream ticket, **D** upstream docs or source (intended behaviour),
**M** our own reproduction, **N** searched and found nothing - always with a
date. Mechanism lives in the subsystem doc, which links back to its rows here.
